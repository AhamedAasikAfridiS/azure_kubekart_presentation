Request Flow

  1. The user signs in through Microsoft Entra ID.
  2. The React frontend communicates with Node.js/Express through an HTTPS REST API using JSON.
  3. Cosmos DB stores application data, while Blob Storage stores images and files.
  4. Service Bus and Azure Functions process notification emails asynchronously.
